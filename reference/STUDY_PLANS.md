## 12-Week Revision Track — 8 hours/week

Use phase assessments first. For each weak area:
1. Read the phase overview.
2. Reconstruct one worked example.
3. Complete the phase lab.
4. Answer interview questions aloud.
5. Review one worked capstone.

## Weekly cadence

- 40% concept and reconstruction
- 35% exercises and coding
- 15% project work
- 10% spaced review and communication

## Daily 90-minute session

1. 10 min: retrieve prior concepts without notes
2. 25 min: new explanation/derivation
3. 35 min: coding and variation
4. 15 min: exercises or error analysis
5. 5 min: learning journal and next experiment
